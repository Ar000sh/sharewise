# The HTTP contract

`docs/api/openapi.yaml` is the source of the HTTP interface; the procedure for changing it is `/contract-change`.
- The contract changes **in its own commit** (`contract(<scope>): ...`); the commit gate refuses it mixed with other files.
- JSON names are the diagram names (`paidBy`, `totalAmount`, `owedShare`, `netBalance`). Money is a decimal string with two digits (`"900.00"`).
- Every error an endpoint can return is listed with its `code`; a new `ErrorCode` also goes into the Java enum and `frontend/src/lib/errors.ts`.
- Each operation has an example, because `docs/api/mock.sh` (Prism) serves the examples to the frontend.
- `frontend/src/api/schema.d.ts` is generated by `npm run gen:api` and never edited by hand (the guard hook blocks it).
- Check: `npx @redocly/cli lint docs/api/openapi.yaml`.
